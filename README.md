
# 燕云十六声 · 丝竹雅韵弹琴助手

一款基于屏幕视觉识别的自动弹琴辅助工具，通过模板匹配和亮度检测，自动识别游戏中的短按/长按音符，并模拟键盘输入，帮助你轻松完成“丝竹雅韵”演奏。

---

## ✨ 特性

- **视觉识别**：利用 OpenCV 模板匹配识别蓝花（短按）、蓝光圈/金圈（长按），并辅以亮度阈值检测光柱，适应多种场景。
- **自动按键**：模拟键盘按压 `S D F J K L`，自动完成短按与长按操作。
- **防抖机制**：支持连续帧确认与消失防抖，避免单帧抖动误触发。
- **参数可调**：识别阈值、冷却时间、长按最短时长、亮度阈值和像素数量均可通过滑块实时调整。
- **窗口选区**：图形化拖拽选择基准线和各轨道位置，配置直观。
- **配置持久化**：支持保存/加载配置文件 (`config.json`)，免去重复设置。
- **进程锁定**：仅当目标游戏窗口处于前台时运行，避免误触其他应用。

## 📦 依赖安装（必须）

### 核心依赖（必须安装）
在命令行（CMD 或 PowerShell）中粘贴并回车：

```bash
pip install opencv-python numpy mss pynput pywin32 psutil
```

各依赖具体用途说明：

| 库名 | 安装命令 | 用途 |
|------|----------|------|
| opencv-python | `pip install opencv-python` | 图像识别（模板匹配 `cv2.matchTemplate`） |
| numpy | `pip install numpy` | 矩阵运算与像素统计（检测亮度像素） |
| mss | `pip install mss` | 极速截取屏幕画面（无黑屏闪烁） |
| pynput | `pip install pynput` | 底层模拟键盘 press / release，解决长按断触问题 |
| pywin32 | `pip install pywin32` | 提供 `win32gui` 和 `win32process`，用于检测前台窗口是否为 `yysls.exe` |
| psutil | `pip install psutil` | 配合 pywin32，获取进程名并判断是否聚焦 |

### 打包依赖（可选）
仅当需要将程序打包成 EXE 时安装：

```bash
pip install pyinstaller
```

### 无需安装的标准库（Python 自带）
以下模块已在 Python 内部，不需要额外安装：

- `tkinter`（UI 界面）
- `json`（保存/读取配置）
- `os`（检查文件夹）
- `time`（延时）
- `threading`（多线程后台运行）

## ⚠️ 避坑提示

- **管理员权限**：无论是运行 `.py` 还是打包后的 `.exe`，**必须右键选择“以管理员身份运行”**。否则 `pynput` 无法注入底层按键，`win32gui` 也无法正确识别前台窗口。
- **安装报错**：如果在安装 `pywin32` 或 `mss` 时遇到网络或版本错误，建议更新 `pip` 后重试：
  ```bash
  python -m pip install --upgrade pip
  ```

## 🎮 使用说明

1. **配置选区**
   - 点击 **“选取基准线 (Y轴)”**，在游戏画面中横向画一条线（即音符判定线），程序会自动记录 Y 坐标。
   - 依次点击 **S / D / F / J / K / L** 按钮，在对应轨道的**中间位置**纵向画一条线，程序会自动扩展为左右各 50 像素的检测区域。
   - 所有轨道配置完成后，状态栏会显示对应坐标。

2. **调整参数**
   - **识别阈值**：模板匹配相似度，一般 0.80~0.95 之间，过高可能漏检，过低可能误触。
   - **短按冷却**：防止同一音符重复触发，建议 0.03~0.10 秒。
   - **长按最短时长**：长按至少持续多久才被认为是有效长按，建议 0.3~1.0 秒。
   - **光柱亮度阈值** & **光柱像素数量**：用于辅助检测长按（当模板匹配不到时）。如果雪地等亮背景导致误触，可调高阈值（如 150—180）和像素数量（如 250—350）。

3. **保存/读取配置**
   - 首次配置好后点击 **“保存配置”**，之后可直接 **“读取配置”** 快速加载。

4. **启动/停止**
   - 点击 **“开始运行”**，工具将自动检测游戏窗口（默认进程名 `yysls.exe`）并开始识别。
   - 点击 **“停止运行”** 或关闭窗口即可停止。

> 注意：运行过程中，游戏窗口必须保持在前台且未被遮挡，否则识别会暂停。

## ❓ 常见问题

- **模板加载失败**：请确保 `templates` 文件夹存在且包含三张截图。
- **没有任何反应**：检查游戏窗口是否在前台，进程名是否正确（默认为 `yysls.exe`）。
- **长按提前释放或无法识别**：适当调整 **长按最短时长** 和 **防抖参数**（代码中 `HOLD_DEBOUNCE` 和 `VISUAL_STREAK` 可自行微调）。
- **雪地/亮背景误触**：提高 **光柱亮度阈值** 和 **光柱像素数量**。
